### 1. 核心基础：Vim 的三种模式

Vim 最核心的特点就是**模式化编辑**，不同模式对应不同操作逻辑，这是新手首先要理解的。

|模式名称|进入方式|主要用途|
|---|---|---|
|**普通模式**|打开文件默认进入，或从其他模式按 `Esc` 返回|移动光标、复制粘贴、删除、执行快捷命令|
|**编辑模式**|在普通模式下按 `i`/`a`/`o` 等键|输入、修改文字内容|
|**命令行模式**|在普通模式下按 `:` 键|保存、退出、查找替换、执行系统命令|


### 2. 快速上手：第一次编辑流程

1. **打开文件**，打开后默认进入**普通模式**。

```bash
vim test.txt
```

2. **进入编辑模式**，按 `i`（在光标前插入）或 `a`（在光标后插入），底部会显示 `-- INSERT --`。

3. **输入内容**，正常输入文字，比如：`Hello, Vim!`

4. **保存并退出**

- 按 `Esc` 回到**普通模式**
- 按 `:` 进入**命令行模式**
- 输入 `:wq` 并回车（`w`= 保存，`q`= 退出）


### 3. 普通模式：高效操作的核心

普通模式是 Vim 最强大的模式，记住这些高频操作，效率会提升很多。

#### 光标移动

- **基础移动**：`h`（左）、`j`（下）、`k`（上）、`l`（右）（替代方向键，纯键盘流更高效）
- **快速跳转**：

    - `gg` → 跳转到文件开头
    - `G` → 跳转到文件末尾
    - `nG` → 跳转到第 `n` 行（如 `5G` 跳转到第 5 行）
    - `^` → 跳转到行首，`$` → 跳转到行尾
    - `w` → 跳转到下一个单词开头，`b` → 跳转到上一个单词开头


#### 复制、粘贴、删除

- **删除**：

    - `x` → 删除光标所在字符
    - `dd` → 删除整行（常用！）
    - `ndd` → 删除从当前行开始的 `n` 行（如 `3dd` 删除 3 行）
    - `d$` → 删除从光标到行尾的内容

- **复制**：

    - `yy` → 复制整行（常用！）
    - `nyy` → 复制从当前行开始的 `n` 行

- **粘贴**：

    - `p` → 粘贴到光标下方
    - `P` → 粘贴到光标上方


#### 撤销与重做

- `u` → 撤销上一步操作
- `Ctrl + r` → 重做撤销的操作

---

### 4. 编辑模式：专注输入

在普通模式下按以下键进入编辑模式，按需选择：

- `i` → 在光标**前**插入（最常用）
- `a` → 在光标**后**插入
- `o` → 在当前行**下方**新建一行并插入
- `O` → 在当前行**上方**新建一行并插入
- `s` → 删除光标所在字符并插入
- `S` → 删除整行并插入

---

### 5. 命令行模式：进阶操作

在普通模式下按 `:` 进入，这里可以执行保存、退出、查找替换等高级操作。

#### 文件操作

- `:w` → 保存文件
- `:q` → 退出（未修改时可用）
- `:wq` → 保存并退出（常用！）
- `:q!` → 强制退出，不保存修改
- `:w 文件名` → 另存为新文件

#### 查找与替换

- **查找**：

    - `/关键词` → 向下查找（按 `n` 找下一个，`N` 找上一个）
    - `?关键词` → 向上查找

- **替换**：

    - `:s/旧内容/新内容` → 替换当前行第一个匹配项
    - `:s/旧内容/新内容/g` → 替换当前行所有匹配项
    - `:%s/旧内容/新内容/g` → 替换整个文件所有匹配项（全局替换）


#### 其他实用命令

- `:set nu` → 显示行号（`set nonu` 关闭行号）
- `:! 命令` → 执行系统命令（如 `:!ls` 查看当前目录文件）
- `:n` → 跳转到下一个文件（多文件打开时）
- `:prev` → 跳转到上一个文件

### 6. 新手必练：vimtutor 内置教程

Vim 自带了一个交互式教程，是最好的入门练习工具。

在终端输入：

```bash
vimtutor
```

它会引导你完成从基础到进阶的所有操作，花 30 分钟跟着练一遍，就能快速上手。

### 7. 避坑指南

1. **卡住了怎么办？** 按 `Esc` 回到普通模式，再输入 `:q!` 强制退出。
2. **方向键不能用？** 试试 `h/j/k/l` 移动光标，这是 Vim 的原生方式。
3. **粘贴内容格式乱了？** 在普通模式下按 `:set paste`，再粘贴，避免自动缩进导致的格式问题。
